## MODX RSC — Russian Speaking Community

Сообщество пользователей CMS [MODX](https://modx.com), говорящих на русском языке.

- Сайт: [modx.pro](https://modx.pro)
- Документация: [docs.modx.pro](https://docs.modx.pro)
- Магазин дополнений: [modstore.pro](https://modstore.pro)
- Почта: [info@modx.pro](mailto:info@modx.pro)

### Репозитории

| Репозиторий | Описание |
| --- | --- |
| [Docs](https://github.com/modx-pro/Docs) | Документация компонентов на docs.modx.pro |
| [pdoTools](https://github.com/modx-pro/pdoTools) | Библиотека быстрых сниппетов для MODX |
| [Tickets](https://github.com/modx-pro/Tickets) | Пользовательские страницы и комментарии |
| [MiniShop3](https://github.com/modx-pro/MiniShop3) | Интернет-магазин для MODX 3 |
| [vueTools](https://github.com/modx-pro/vueTools) | Vue-стек для компонентов MODX 3.x |
| [modx-ace](https://github.com/modx-pro/modx-ace) | Редактор ACE в менеджере MODX |

Полный список: [github.com/modx-pro](https://github.com/modx-pro).

### Участие

Issues и pull request'ы принимаем в соответствующих репозиториях. Документацию для [Docs](https://github.com/modx-pro/Docs) пишите по правилам из `AGENTS.md` / [guide](https://docs.modx.pro/guide/).
